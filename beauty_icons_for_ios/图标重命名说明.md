## 📝 操作步骤

1. **复制图标文件**：将此文件夹中的所有 `.png` 文件复制到 `iOS/AgoraEntScenarios/Scenes/Show/showResource.bundle/`

2. **重命名文件**：按照上表将需要重命名的文件（标记 ⚠️ 的）进行重命名

3. **创建高分辨率版本**：为每个图标创建 `@3x.png` 版本
   ```bash
   # 示例：为每个图标创建@3x版本
   cp show_beauty_none.png show_beauty_none@3x.png
   cp meiyan_makeup_diadiatu.png meiyan_makeup_diadiatu@3x.png
   # ... 其他文件
   ```

4. **创建缺失的 Animoji 图标**：
   - 复制 `show_beauty_none.png` 并重命名为 `kaola_Animoji.png`
   - 复制 `show_beauty_none.png` 并重命名为 `hashiqi_Animoji.png`
   - 为这两个文件也创建 `@3x.png` 版本
